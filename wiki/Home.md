# Welcome to [TeeGrid](https://www.steema.com/product/gridnet) for .NET

TeeGrid for NET is a native c# Grid control currently available for Winform projects and for use as an ASP.Net Core MVC grid rendering to directly to native HTML & [jsGrid](http://js-grid.com/) grids.
